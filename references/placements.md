# Placements

Common defaults. Platforms change specs, so confirm before a big campaign.

| Key | Size | Ratio | Platform | Use |
|---|---|---|---|---|
| `meta_square` | 1080 × 1080 | 1:1 | Facebook / Instagram | Feed post |
| `meta_portrait` | 1080 × 1350 | 4:5 | Facebook / Instagram | Feed post (takes more screen) |
| `meta_story` | 1080 × 1920 | 9:16 | Facebook / Instagram | Stories, Reels cover |
| `linkedin_square` | 1200 × 1200 | 1:1 | LinkedIn | Feed image post |
| `x_post` | 1600 × 900 | 16:9 | X | In-feed image post |
| `pinterest` | 1000 × 1500 | 2:3 | Pinterest | Standard pin |
| `link_preview` | 1200 × 630 | ~1.91:1 | Facebook, X, LinkedIn | Link preview / Open Graph image |

## Which placements to suggest per platform
- **Meta:** `meta_square`, `meta_portrait`, `meta_story`
- **LinkedIn:** `linkedin_square`, `link_preview`
- **X:** `x_post`, `link_preview`
- **Pinterest:** `pinterest`

## Safe zones
- `meta_story`: keep text out of the top ~14% and bottom ~20% (profile bar, reply box). The script does this automatically.

## Caption limits (keep well under)
| Platform | Limit | Practical target |
|---|---|---|
| Instagram | 2,200 characters | First 125 characters carry the message (cut off after) |
| Facebook | very long | 40–80 characters perform best |
| LinkedIn | 3,000 characters | First ~140 characters show before "see more" |
| X | 280 characters | Link goes in a reply |
| Pinterest | Title 100, description 500 | Use keywords people search for |
